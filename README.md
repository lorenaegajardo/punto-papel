# Punto Papel

Punto Papel es una tienda online ficticia de artículos de librería y papelería, desarrollada como trabajo práctico grupal para la materia Construcción de Interfaces de Usuario de la Universidad Nacional de Hurlingham (UNAHUR).

El proyecto permite explorar productos, consultar sus detalles, agregarlos a un carrito y simular una compra mediante un formulario.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- React Bootstrap
- React Router
- CSS
- Git y GitHub

## Funcionalidades implementadas

- Página de inicio con presentación de la tienda.
- Catálogo de 12 productos con imágenes, precios y categorías.
- Búsqueda, filtros por categoría y ordenamiento por precio.
- Vista de detalle de cada producto.
- Carrito de compras con modificación de cantidades y eliminación de productos.
- Cálculo automático de subtotales y total de la compra.
- Actualización del stock disponible según los productos agregados al carrito.
- Persistencia del carrito mediante `localStorage`.
- Formulario de compra con validación de campos obligatorios.
- Confirmación simulada de compra.
- Diseño responsive, adaptable a computadoras, tablets y celulares.

## Instalación y ejecución

Para ejecutar el proyecto localmente es necesario tener instalados Node.js y npm.

1. Clonar el repositorio:

   `git clone https://github.com/lorenaegajardo/punto-papel.git`

2. Ingresar a la carpeta del proyecto:

   `cd punto-papel`

3. Instalar las dependencias:

   `npm install`

4. Iniciar el servidor de desarrollo:

   `npm run dev`

5. Abrir en el navegador la dirección indicada por Vite, generalmente `http://localhost:5173/`.

## Compilación para producción

Para generar la versión de producción:

`npm run build`

Los archivos generados se guardan en la carpeta `dist`.

Para comprobar el código con ESLint:

`npm run lint`

## Aclaración sobre las compras

Punto Papel es un proyecto educativo. Las compras son simuladas y no se realizan pagos reales ni se envían pedidos a una tienda.
